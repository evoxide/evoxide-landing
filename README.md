# EVOXIDE Landing

Landing page for EVOXIDE.

## Requirements

- Bun 1.3.13 or newer

## Quick start

```sh
bun install
bun run dev
```

## Commands

```sh
bun run dev --host 127.0.0.1 --port 4321
bun run build
bun run preview
```

The production build is written to `dist/client/`.

## Troubleshooting

```sh
bun install --frozen-lockfile
bun run build
```
